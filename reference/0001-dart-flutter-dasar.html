Cheat Sheet: Dart & Flutter Dasar

Kompresi dari Lesson 001. Cetak atau simpan buat lihat cepat.

Glosarium cepat

IstilahDefinisi
FlutterUI toolkit open-source buatan Google; satu codebase → Android, iOS, web, desktop.
DartBahasa pemrograman (Google) yang dipakai untuk menulis seluruh kode Flutter.
Hot ReloadPerubahan kode langsung terlihat di emulator/device tanpa kehilangan state app.
WidgetUnit penyusun UI di Flutter — semuanya adalah widget.
Widget treeHierarki/pohon susunan widget dari root sampai ke elemen UI terkecil.
StatelessWidgetWidget tanpa state internal yang berubah (UI statis: Text, Icon).
StatefulWidgetWidget dengan state yang bisa berubah saat runtime (form, counter, animasi).
Null safetyNilai tidak boleh null kecuali dinyatakan eksplisit dengan ?.
Type inferenceDart menebak tipe otomatis via var tanpa harus menuliskan tipe.
MaterialAppWidget root yang mengatur tema & navigasi ala Material Design.
ScaffoldKerangka halaman (AppBar, body, FAB) — layout dasar satu layar.
Cross-platformKode yang sama bisa jalan di banyak platform tanpa ditulis ulang.

Tipe data dasar Dart

int umur = 28;          // bilangan bulat
double ipk = 3.93;      // bilangan desimal
bool isDosen = true;    // true / false
String nama = 'Anemia'; // teks
var nilai = 10;         // type inference: Dart menebak int

Pola "Hello World" Flutter

import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      theme: ThemeData(colorSchemeSeed: Colors.blue, useMaterial3: true),
      home: const Scaffold(
        body: Center(child: Text('Halo!', style: TextStyle(fontSize: 24))),
      ),
    );
  }
}

Perintah CLI yang sering dipakai

PerintahFungsi
flutter doctorCek kesehatan toolchain Flutter.
flutter create nama_projectBuat project baru.
flutter runJalankan app di device/emulator.
flutter testJalankan unit/widget test.
flutter analyzeStatic analysis — cari warning/error di kode.
dart run bin/file.dartJalankan script Dart murni (tanpa Flutter).

Arsitektur Flutter (3 lapis)

  1. Framework (Dart) — tempat menulis kode: widget, gesture, animasi, painting.
  2. Engine (C/C++) — rendering (Skia/Impeller), text layout, Dart runtime.
  3. Embedder — komunikasi dengan OS (Android: Java/Kotlin; iOS: Obj-C/Swift).
