# Mission: Flutter & Dart (Mobile Programming)

## Why
Saya harus lulus mata kuliah Mobile Programming (materi dosen Arif Hidayah, 16 modul Flutter) DAN punya fondasi yang cukup buat bikin app sendiri — rencana utama: aplikasi seputar **Anemia** (cek/edukasi/tracking). Flutter ini jadi jalan utamanya karena satu codebase bisa jalan di Android, web, dan di mana-mana.

## Success looks like
- Nyelesaiin 16 modul dosen secara berurutan, tiap modul ada praktik + learning record-nya.
- Bisa bikin UI Flutter sendiri (widget, layout, navigasi) tanpa nanya AI tiap baris.
- Bisa connect REST API + simpan data lokal (SQLite) — fondasi buat app anemia.
- Build & install APK app anemia ke HP sendiri (atau 'flutter run' ke emulator/Chrome).
- `flutter analyze` bersih dan `flutter test` hijau di project `anemia`.

## Constraints
- Java: bahasa percakapan (gue jawab Bahasa Indonesia, santai).
- Lingkungan: Windows 11, Flutter 3.47.5 stable + Dart 3.13.4 (baru diinstall, PATH persistent aktif di terminal baru).
- Belajar sambil ikutin urutan materi dosen dari modul 1.

## Out of scope
- Fokus ke web development lain (React, Vue, dsb.) — belum.
- Native Android native (Kotlin) dalam-dalam — cukup paham konteks embedder-nya saja.
- Backend/server-side kompleks — cukup buat nyambung ke REST API yang ada.
