REST API — 30 detik

Model + fromJson — jangan main Map mentah

class UserPasien {
  final int id; final String nama; final String email; final String kota; final String website;

  factory UserPasien.fromJson(Map<String, dynamic> json) {
    final address = json['address'] as Map<String, dynamic>?;
    return UserPasien(
      id: json['id'] as int, nama: json['name'] as String,
      email: json['email'] as String,
      kota: (address?['city'] as String?) ?? '',
      website: (json['website'] as String?) ?? '',
    );
  }
}

FutureBuilder — 3 keadaan otomatis

FutureBuilder<List<UserPasien>>(
  future: _future,
  builder: (context, snap) {
    if (snap.connectionState == ConnectionState.waiting) return loading;
    if (snap.hasError) return errorUI;   // + tombol "Coba lagi"
    return ListView.separated(...);      // sukses
  },
)

JANGAN panggil API di build()

future: fetchData() langsung di build = tiap rebuild request ulang. Simpan di state:

@override
void initState() { super.initState(); _future = _service.getUsers(); }

Future<void> _refresh() {
  setState(() { _future = _service.getUsers(); });  // block body, bukan arrow!
}

Bug yang gue temuin di kode sendiri pas nulis ini: setState(() => _future = ...) — arrow return Future → Flutter nge-assert itu (gak boleh kerja async di dalam setState). Fix: block body. Bug nyata, ketauan karena test. 🤓

Tugas praktik (10 menit)

  1. flutter run → tab Direktori → list pasien dari server beneran muncul (butuh internet!). Tarik ke bawah → pull-to-refresh jalan.
  2. Klik salah satu pasien → detail (nama, email, kota, website).
  3. Ikon ➕ di AppBar → isi Nama & Email → Simpan → SnackBar hijau. Matiin internet → coba lagi → SnackBar merah. (Catatan: JSONPlaceholder nggak nyimpen beneran — pas refresh data bales ke 10 user asli. Itu wajar, API demo.)
  4. Tantangan dosen: tambah tombol "Muat Ulang" ↻ yang udah ada di AppBar Direktori — coba hubungin ke error state (pasti bareng "Coba lagi").
  5. Tantangan dosen (opsional): bikin halaman pembaca /posts kayak contoh dosen di project terpisah.

Kuis singkat

Q1: Ambil data dari server = method…

GET = ambil, POST = tambah, PUT/PATCH = ubah, DELETE = hapus.

Q2: Cek suksesnya request = lihat…

200 sukses GET, 201 sukses POST, 404 nggak ketemu, 500 server error.

Q3: Ubah JSON jadi object Dart pakai…

UserPasien.fromJson(json) — pola type-safe, bukan kerja dengan Map mentah.

Q4: Loading / error / sukses sekaligus = pakai…

FutureBuilder kasih state otomatis: waiting → loading, hasError → error, data! → sukses.

Q5: Panggil API tiap rebuild = salah. Pola yang bener…

Future dibuat sekali di initState, di-refresh lewat setState block body.
