Flutter itu apa sih, dan kenapa pake Dart?

Materi asli dosen: Modul 1: Pengenalan Flutter & Dart.

Sebelum ngoding app Anemia kamu, kita perlu tahu dulu dua kata kunci: Flutter (framework UI) dan Dart (bahasanya). Satu kalimat rangkumannya: Flutter adalah alatnya, Dart adalah bahasanya.

1. Flutter = UI toolkit cross-platform

Flutter buatan Google untuk bikin aplikasi dari satu codebase yang bisa jalan di Android, iOS, web, dan desktop. Kode kamu dikompilasi langsung ke kode mesin native — bukan lewat "jembatan" seperti React Native. Efeknya: performa hampir secepat native.

Kenapa ini penting buat kamu? Karena app Anemia yang kamu bangun sekali bisa dipakai di HP Android (temannya iOS juga), versi web, dan desktop — tanpa nulis ulang.

2. Dart = bahasanya

Dart itu bahasa modern buatan Google: object-oriented, null-safe, dan mendukung async/await. Semua kode Flutter ditulis pakai Dart.

Coba ini — contoh dari dosen, jalankan di project kamu:

void main() {
  // Variabel dengan type inference
  var nama = 'Arif Hidayah';
  int umur = 28;
  double ipk = 3.93;
  bool isDosen = true;

  print('Halo, saya $nama');
  print('Umur: $umur, IPK: $ipk');
}

Sudah ada di bin/hello_dart.dart — jalankan dengan:

> dart run bin/hello_dart.dart

3. Empat fitur Dart yang wajib kamu kenal sekarang

FiturArti sederhananya
Null safetyVariabel gak bisa null kecuali kamu paksa pakai ?. Mencegah error "null" waktu runtime.
Type inferenceDart bisa nebak tipe lewat var — tapi kamu tetap bisa tulis eksplisit: int, double, bool, String.
Async/awaitUntuk panggil API / database tanpa bikin app nge-freeze. Datang di modul 5.
OOP lengkapClass, inheritance, mixin, abstract — cara Dart rapihin kode besar. Datang di modul 4.

4. Di Flutter, semuanya Widget

Tombol itu widget. Padding itu widget. Layar itu widget. Semua tersusun jadi widget tree (pohon widget). Dua jenis dasarnya:

JenisKapan dipakaiContoh
StatelessWidgetUI statis, gak berubahText, Icon, tampilan "Halo Mahasiswa"
StatefulWidgetUI yang berubah saat runtimeForm input, counter, animasi

Contoh app paling polos dari dosen (sudah dipasang di lib/main.dart):

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      theme: ThemeData(colorSchemeSeed: Colors.blue, useMaterial3: true),
      home: const Scaffold(
        body: Center(
          child: Text('Halo Mahasiswa! 🎓', style: TextStyle(fontSize: 24)),
        ),
      ),
    );
  }
}

5. Arsitektur Flutter (3 lapis)

Framework (Dart) tempat kamu nulis kode → Engine (C/C++) mesin render & runtime Dart → Embedder bicara ke OS (Android/iOS/web). Kamu cukup sentuh lapisan paling atas.

Latihan cepat (5 menit)

  1. Jalankan dart run bin/hello_dart.dart — lihat output-nya.
  2. Jalankan flutter test — test kita memastikan teks "Halo Mahasiswa! 🎓" muncul.
  3. (Bonus) Ubah fontSize: 24 jadi fontSize: 32 di lib/main.dart, lalu flutter test lagi — masih hijau kalau kamu gak merusak test-nya.

Kuis singkat

Q1: Flutter itu…

Flutter adalah framework UI (toolkit). Bahasa yang dia pakai adalah Dart.

Q2: Bahasa pemrograman untuk menulis app Flutter adalah…

Semua kode Flutter ditulis dalam Dart.

Q3: Widget yang cocok untuk input form (berubah saat runtime) adalah…

Form input / konten interaktif butuh state yang berubah → StatefulWidget. Stateless untuk UI statis; Scaffold adalah layout dasar, bukan jenis widget state.
