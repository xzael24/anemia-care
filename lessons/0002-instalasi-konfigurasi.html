Cara menyalakan aplikasi (ini skill pentingnya)

PerintahMaknanya
flutter runJalankan di emulator/device Android yang aktif
flutter run -d chromeJalankan versi web di browser
flutter emulators --launch Medium_PhoneNyalakan emulator Android dari sini
tekan r di terminal saat app jalanHot Reload — ganti kode, langsung keliatan tanpa restart
tekan RHot Restart — reload penuh dari nol

Tugas praktik (5 menit)

  1. Nyalakan emulator: flutter emulators --launch Medium_Phone
  2. Di terminal project: flutter run — tunggu app "Halo Mahasiswa! 🎓" muncul di emulator.
  3. Coba hot reload: ubah teks di lib/main.dart jadi 'Halo dari Anemia! 🩸', simpan, tekan r. Perubahan langsung muncul — tanpa restart app.
  4. Beres? Tekan q untuk keluar dari flutter run.
Tidak ada emulator di laptop? flutter run -d chrome juga sah — app yang sama jalan di web.

Kuis singkat

Q1: Semua kode Dart kamu ditulis di folder…

lib/ adalah ⭐ kode utama. test/ untuk test, android/ native (jangan disentuh dulu).

Q2: File tempat mendaftarkan dependensi (package) adalah…

pubspec.yaml = daftar package. pubspec.lock otomatis & jangan diedit manual.

Q3: Saat app sedang jalan, tombol untuk Hot Reload adalah…

r = hot reload (cepat, state dipertahankan), R = hot restart, q = keluar.
