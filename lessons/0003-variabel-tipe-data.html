Data pasien anemia mulai disimpan ke variabel

Materi asli dosen: Modul 3: Variabel & Tipe Data di Dart.

Aplikasi itu pada dasarnya cuma data yang disimpan, diproses, lalu ditampilkan. Di modul ini kamu belajar wadah data paling dasar di Dart: variabel — plus aturan mainnya (tipe data, null safety) yang bakal kamu pakai terus sampai modul 16.

Kenapa penting buat app anemia kamu? 🩸

Nilai hemoglobin, umur pasien, status anemia / normal — semuanya bakal hidup di variabel. Salah pilih tipe data = bug diam-diam (contoh: Hb 10.2 jadi 10 karena dipaksa int). Modul ini yang bikin kamu nggak gampang kena jebakan kayak gitu.

1. Cara mendeklarasikan variabel

CaraMaksudnyaContoh
varTipe ditentukan otomatis dari nilainya (type inference)var hemoglobin = 10.2; → double
Tipe eksplisitKamu yang nentuin tipenya, nggak nebak-nebakString golonganDarah = 'A';
finalSekali di-assign, nggak bisa diubah (nilai baru ketahuan pas jalan)final kodePasien = 'PSN-0001';
constKonstanta compile-time (angkanya sudah pasti dari awal)const batasHbNormal = 12.0;
final vs const: final nilainya bisa dihitung saat runtime (misal final sekarang = DateTime.now();), sedangkan const harus sudah ketahuan sebelum program jalan (misal const pi = 3.14;).

2. Tipe data dasar (built-in types)

TipeIsinyaContoh di app anemia
intBilangan bulatint umur = 22;
doubleBilangan desimaldouble hemoglobin = 10.2;
numSupertype dari int & double (bisa keduanya)num nilaiLab = 99;
StringTeksString nama = 'Silvi';
booltrue / falsebool berisikoAnemia = true;
dynamicBebas ganti tipe kapan ajadynamic x = 10; x = 'teks';
dynamic itu fleksibel tapi berbahaya — kalau bisa, selalu pilih tipe yang jelas. Kalau di flutter analyze muncul peringatan soal ini, itu lagi nolongin kamu.

3. String interpolation — $ itu magic

Pakai $namaVariabel (atau ${ekspresi} untuk kalkulasi) biar teksnya otomatis ke-isi:

print('Nama: $nama, Hb: $hemoglobin g/dL');
print('Status: ${hemoglobin < batasHbNormal ? "ANEMIA" : "normal"}');

4. Collection: List, Map, Set

List<String> gejala = ['lemah', 'pucat', 'pusing'];
gejala.add('sesak napas');          // tambah
print(gejala.length);               // 4

Map<String, dynamic> hasilLab = {
  'hemoglobin': 10.2,
  'mcv': 74.3,
};
print(hasilLab['hemoglobin']);      // 10.2

Set<String> golDarahKamar = {'A', 'B', 'O', 'A'};
print(golDarahKamar);               // {A, B, O} — duplikat auto dibuang

5. Null Safety — ciri khas Dart modern ⭐

Sejak Dart 2.12, variabel nggak boleh null secara default. Kalau butuh boleh kosong, kasih tanda ?:

OperatorMaknaContoh
?Variabel boleh nulldouble? hbSebelum;
?.Akses hanya kalau tidak null (aman)alamat?.toUpperCase()
??Nilai default kalau nullhbSebelum ?? 'belum ada hasil'
!Paksa non-null — hati-hati, bisa crashdata!.nama
lateTunda inisialisasi non-nullablelate String token;

6. Konversi tipe (sering banget kepake)

var inputForm = '12.5';              // dari TextField, selalu String
double hb = double.parse(inputForm); // String → double
print(hb.toStringAsFixed(1));        // '12.5' (double → String)
print(hb.toInt());                   // 12 (terpotong, hati-hati kalau data lab!)

Kuis singkat

Q1: var hemoglobin = 10.2; — tipe hemoglobin adalah…

var mengambil tipe dari nilainya. Karena 10.2 ada desimalnya, Dart menyimpannya sebagai double.

Q2: Kata kunci yang nilainya tidak bisa diubah setelah di-assign…

final sekali di-assign langsung terkunci. var dan dynamic masih bisa diubah nilainya.

Q3: String? alamat; artinya alamat…

Tanda ? membuka izin null. Tanpa ?, variabel wajib punya nilai sejak awal.

Q4: Operator nilai default saat variabel null…

?? = "kalau null, pakai ini". ?. = akses aman, ! = paksa non-null (berbahaya).
