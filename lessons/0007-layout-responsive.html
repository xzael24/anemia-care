Dashboard anemia menyesuaikan layar

Materi asli dosen: Modul 7: Layout & Responsive Design.

App kamu bakal jalan di HP 5", HP 6.7", tablet, dan desktop. Modul ini ngajarin layout yang fleksibel — dan di misi kita, Kartu Pasien dari Modul 6 naik kelas jadi Dashboard Anemia lengkap: ringkasan, menu grid, dan daftar pasien dalam satu halaman yang bisa di-scroll dan adaptif.

Aturan emas layout: Constraint Flow 📐

  1. Constraint (batasan ukuran) mengalir turun: parent → child
  2. Size mengalir naik: child → parent
  3. Parent menentukan posisi child

Melanggar aturan ini = error "Vertical viewport was given unbounded height" yang terkenal itu.

Expanded & flex — gambarannya

Row(children: [
  Expanded(flex: 2, child: merah),  // 2/3 ruang
  Expanded(flex: 1, child: hijau),  // 1/3 ruang
])

Di dashboard: tiga Expanded tanpa flex (default 1) = tiga kartu sama lebar.

Stack + Positioned — badge di pojok

Stack(clipBehavior: Clip.none, children: [
  CircleAvatar(child: Icon(Icons.person)),
  Positioned(right: -2, bottom: -2,
    child: Container(width: 14, height: 14,
      decoration: BoxDecoration(color: merah/ijo, shape: BoxShape.circle))),
])

ListView vs GridView — kapan pake yang mana

ListView.builder(
  itemCount: 100,
  itemBuilder: (context, i) => ListTile(title: Text('Item $i')),
)

GridView.count(
  crossAxisCount: 2,          // jumlah kolom
  mainAxisExtent: 96,         // tinggi tiap sel (biar pendek)
  children: [...],
)

GridView/menu di dalam scroll view → wajib shrinkWrap: true + physics: NeverScrollableScrollPhysics() biar nggak dobel-scroll & error unbounded.

Responsive: MediaQuery vs LayoutBuilder

AlatBaca apaKapan

Mini project hari ini: Dashboard Anemia 🩺

Udah kubuat di lib/main.dart: ringkasan (Total/Anemia/Normal — logika where dari Modul 5!), menu grid adaptif (2→4 kolom), daftar pasien dengan badge status. Di-verifikasi: flutter analyze No issues, flutter test pass (cek jumlah ANEMIA = 3 dari data 6 pasien).

Tugas praktik (10 menit)

  1. Jalankan flutter run -d chrome, lalu drag-ubah lebar jendela browser → menu grid berubah 2↔4 kolom. Itu cara tercepat tes responsif tanpa device.
  2. Tekan tombol aspect_ratio di AppBar → SnackBar muncul berisi ukuran layar (MediaQuery).
  3. Ubah no. 1: ganti ambang kolom dari 600 jadi 400 di LayoutBuilder → lihat perubahannya.
  4. Ubah no. 2 (tantangan dosen): tambah 1 item menu lagi di _menu (misal "Rumah Sakit") + 1 pasien di daftar.

Kuis singkat

Q1: Widget untuk membagi ruang proporsional…

Expanded membagi sisa ruang bertflex. Stack menumpuk, SafeArea mengamankan dari notch.

Q2: Widget untuk menumpuk widget di atas widget…

Stack = tumpukan (mirip z-index). Row = sejajar horizontal. Positioned dipakai di dalam Stack.

Q3: Daftar banyak item, render seperlunya pakai…

ListView.builder lazy — item yang nggak keliatan nggak di-render. ListView biasa render semua sekaligus.

Q4: Menjaga konten dari tertutup notch/kamera…

SafeArea otomatis nambah padding di area yang terpotong (notch, status bar). Padding manual nilai tetap.

Q5: Responsif berdasarkan lebar parent, pakai…

LayoutBuilder baca constraint parent; MediaQuery baca ukuran layar device.
