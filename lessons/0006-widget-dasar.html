Konsep: Widget Tree 🌳

UI Flutter = pohon widget. Widget punya child, child punya anak lagi:

EdgeInsets — cara nulis padding/margin

CaraMakna
EdgeInsets.all(16)semua sisi 16
EdgeInsets.symmetric(h: 16, v: 8)kiri-kanan 16, atas-bawah 8
EdgeInsets.only(left: 8)sisi tertentu saja
EdgeInsets.fromLTRB(8,16,8,0)Left, Top, Right, Bottom

Catatan dari kode kita: errorBuilder bikin app tetap aman kalau gambar gagal dimuat (offline dsb) — langsung ganti ikon fallback.

Tombol-tombol

ElevatedButton(onPressed: () {}, child: const Text('Simpan'));   // utama
TextButton(onPressed: () {}, child: const Text('Batal'));        // teks doang
OutlinedButton(onPressed: () {}, child: const Text('Detail'));   // border
IconButton(onPressed: () {}, icon: const Icon(Icons.delete));    // ikon
ElevatedButton.icon(icon: ..., label: const Text('Kirim'));      // ikon + teks

onPressed: null → tombol otomatis ke-disable.

Tugas praktik (10 menit)

  1. Jalankan app: flutter run (emulator/Chrome) — lihat kartu pasien muncul.
  2. Ubah no. 1: ganti nama 'Silvi Rahmawati' jadi nama sendiri → hot reload r → langsung berubah.
  3. Ubah no. 2: ganti colorSchemeSeed: Colors.red jadi Colors.teal → hot reload → warna seluruh app berubah. Itu kekuatan theme.
  4. Ubah no. 3 (tantangan dosen): tambah satu baris info pasien (misal umur) + satu tombol baru bebas.

Kuis singkat

Q1: Kerangka Material Design untuk halaman…

Scaffold = kerangka halaman (AppBar, body, dsb). Container kotak serbaguna, Column penyusun vertikal.

Q2: Padding semua sisi sama, pakai…

all(16) = empat sisi 16. symmetric beda horizontal/vertikal. fromLTRB empat nilai bebeda.

Q3: Susun widget ke bawah (vertikal)…

Column vertikal, Row horizontal, SizedBox cuma spacer.

Q4: Spacer vertikal di dalam Column…

Di Column, SizedBox(height) = jarak vertikal. width kepake di Row.

Q5: Tombol yang paling menonjol (utama)…

ElevatedButton = utama (punya background). TextButton teks polos, OutlinedButton berborder.
