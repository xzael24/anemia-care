Pasien anemia jadi class, paham widget nggak terasa

Materi asli dosen: Modul 4: Function & OOP di Dart.

Tulang punggung Flutter. Di Flutter, semuanya adalah widget, dan setiap widget adalah class. Modul ini yang bikin kode app anemia kamu rapi: data pasien dibungkus jadi class Pasien, alur skrining jadi fungsi, dan modul-modul UI selanjutnya (6+) baru masuk akal setelah kamu paham class.

1. Function dasar + arrow

int tambah(int a, int b) {   // blok biasa, multi-baris
  return a + b;
}

int kali(int a, int b) => a * b;  // arrow: body cuma 1 ekspresi

void log(String pesan) {     // void = nggak ngembaliin nilai
  print('[LOG] $pesan');
}

2. Named & optional parameters ⭐

Di Flutter, semua widget constructor pakai named parameters — contoh Text('Halo', style: TextStyle(fontSize: 20)). Pahami ini sebelum modul UI:

JenisDibungkusContoh
Positional (wajib)—tambah(3, 5)
Named{}profil(nama: 'Arif', umur: 28) — urutan bebas, required kalau wajib
Optional positional[]sapa('Arif', 'Pak') — boleh di-skip, pakai nilai default

3. Class & Object (dengan tema pasien anemia)

class Pasien {
  String nama;
  double hemoglobin;
  const batasHb = 12.0;

  Pasien({required this.nama, required this.hemoglobin}); // this.x = langsung assign

  bool get berisikoAnemia => hemoglobin < batasHb; // getter + logika
  String info() => '$nama — Hb $hemoglobin → ${berisikoAnemia ? 'ANEMIA' : 'normal'}';
}

Encapsulation: Dart nggak punya private — gantinya underscore _ di depan nama (misal String _kode). Property itu hanya bisa diakses dari file yang sama; dari file lain error.

4. Inheritance & Polymorphism

class Hewan { void suara() => print('bersuara...'); }

class Kucing extends Hewan {
  @override
  void suara() => print('Meow! 🐱');   // override = ubah perilaku parent
}

List<Hewan> hewan = [Kucing(), Anjing()]; → saat h.suara() dipanggil, Dart otomatis pakai versi sesuai object aslinya. Itu polymorphism.

5. Abstract class — kontrak "harus bisa apa"

abstract class Bentuk {
  double luas();      // tanpa body → WAJIB diimplementasikan child
  double keliling();

  void info() => print('...');  // abstract boleh punya method konkret
}

Buat kontrak skrining: setiap jenis skrining harus bisa bilang "terindikasi atau nggak", tapi caranya beda-beda. implements (bukan extends) dipakai kalau mau paksa implement semua tanpa mewarisi.

6. Mixin — "tempel" kemampuan, hindari multiple inheritance

mixin BisaTerbang { void terbang() => print('Terbang! ✈️'); }
class Burung with BisaTerbang { ... }  // dengan keyword with, bisa banyak mixin

Rangkuman — 4 pilar OOP di Dart

PilarCara di Dart
EncapsulationUnderscore _nama (private level file)
Inheritanceextends — warisi dari parent class
Polymorphism@override — ubah perilaku method parent
Abstractionabstract class — blueprint tanpa implementasi langsung

Kuis singkat

Q1: Function yang tidak mengembalikan nilai, tipe kembaliannya…

void = "tidak ada nilai kembali". int/null salah — null pun itu sebuah nilai.

Q2: Named parameter dibungkus dengan…

{} = named, [] = optional positional, () = daftar parameter biasa.

Q3: this.nama di constructor artinya…

this.nama langsung meng-assign parameter ke property class, menyingkat penulisan.

Q4: Keyword untuk mewarisi dari class lain…

extends = wariskan. with = mixin. implements = paksa implementasikan.

Q5: Keyword untuk menempelkan mixin…

with dipakai setelah class: class Bebek with BisaTerbang { }.
