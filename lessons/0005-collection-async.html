Materi asli dosen: Modul 5: Collection & Async di Dart.

Dua skill yang bakal lo pakai SETIAP HARI di Flutter: ngolah kumpulan data (list pasien dari API → tampil di ListView) dan ngambil data tanpa nge-freeze app (async/await). App anemia lo: daftar pasien, riwayat hemoglobin, panggilan ke database — semua di sini.

1. List, Set, Map — pilih yang mana?

TipeCiriContoh di app anemia

SetUnik, auto buang duplikat + union/intersection/differencekode pasien yang sudah diskrining

2. Spread & collection operators — literal jadi "hidup"

var semua = [0, ...awal, 4, 5];          // spread: gabung list

var menu = [
  'Home',
  'Profile',
  if (isAdmin) 'Admin Panel',            // collection if
];

var kuadrat = [for (var n in angka) n * n];  // collection for

3. Higher-order methods — ganti loop manual ⭐

var kuadrat = angka.map((n) => n * n).toList();      // transformasi
var genap   = angka.where((n) => n % 2 == 0).toList(); // saring
var total   = angka.reduce((a, b) => a + b);           // akumulasi
angka.any((n) => n > 4);      // ada yang >4?  → true
angka.every((n) => n > 0);    // semua >0?    → true

4. Future & async/await — jangan sampai UI nge-freeze

Future<String> ambilData() async {
  print('Mengambil data...');
  await Future.delayed(Duration(seconds: 2)); // simulasi jaringan
  return 'Data berhasil diambil!';
}

void main() async {
  String hasil = await ambilData(); // nunggu, tapi thread tetap jalan
  print(hasil);
}

Aturan: await hanya boleh di dalam fungsi bertanda async. Tanpa await, kode lanjut dulu tanpa nunggu — itu yang bikin bug "data belum ada" di Flutter.

5. Error handling — wajib di operasi yang bisa gagal

try {
  var user = await ambilUser(-1);
  print(user);
} catch (e) {
  print('Error: $e');   // jaringan putus, server 500, dsb.
} finally {
  print('Proses selesai');
}

6. Stream — data datang bertahap

Stream<int> hitungMundur(int dari) async* {  // async* + yield
  for (int i = dari; i >= 0; i--) {
    await Future.delayed(Duration(seconds: 1));
    yield i;
  }
}

await for (var n in hitungMundur(3)) { ... }  // 3, 2, 1, 0
KonsepSatu nilai?Cara buat
FutureYa, satu nilai di masa depanasync / await
StreamTidak — banyak nilai bertahapasync* / yield, baca dengan await for

Tugas praktik (7 menit)

  1. Jalankan: dart run bin/collection_async_anemia.dart — perhatiin urutan print: baris "Mengambil hasil lab..." → tunggu 2 detik (terasa!) → hasilnya. Itu async.
  2. Ubah no. 1: tambah 'Gina' di daftar ['Eka', 'Fajar'] → total data pasien jadi 6.
  3. Ubah no. 2: ganti ambang filter anemia dari < 12.0 jadi < 11.0 → siapa yang hilang dari daftar anemia?
  4. Ubah no. 3: Duration(seconds: 2) → seconds: 5 → jalanin lagi. Aplikasi tetap "jalan" selama nunggu — itu bedanya async vs freeze.

Kuis singkat

Q1: Method untuk menyaring elemen collection…

where = saring dengan kondisi. map = transformasi. reduce = akumulasi.

Q2: await hanya boleh dipakai di fungsi bertanda…

await butuh async. async* itu untuk Stream (pakai yield).

Q3: Future mengembalikan … di masa depan

Future = satu nilai yang belum ada sekarang. Banyak nilai bertahap itu Stream.

Q4: Stream dibuat dengan tanda…

async* + yield = Stream. async + return = Future.

Q5: Elemen muncul hanya jika kondisi true, pakai…

Collection if: [if (kondisi) elemen]. Collection for untuk perulangan di literal.
