# Memahami perbedaan Flutter vs Dart dan status lingkungan dev

Modul 1 selesai: mahasiswa memahami Flutter = UI toolkit cross-platform, Dart = bahasa pemrogramannya (dibuktikan lewat pertanyaan recall, jawab benar tanpa melihat catatan). Lingkungan dev sudah penuh terpasang: Flutter 3.47.5 stable, Dart 3.13.4, project `anemia` dibuat, contoh dosen sudah diterapkan di `lib/main.dart` ("Halo Mahasiswa! 🎓") dan `bin/hello_dart.dart`, `flutter test` serta `flutter analyze` hijau.

## Implications
- Modul 2 (Instalasi & Konfigurasi) bisa dijalankan sebagai *verifikasi* ketimbang instalasi dari nol — sebagian besar prasyarat sudah dipenuhi sendiri sebelumnya (Flutter SDK, PATH, Android SDK + cmdline-tools + lisensi, VS Code mungkin perlu dicek ekstensi).
- Zona perkembangan berikutnya: langsung masuk ke perintah-perintah dev loop (`flutter run`, hot reload) dan struktur project, baru Modul 3 (Variabel & Tipe Data).
